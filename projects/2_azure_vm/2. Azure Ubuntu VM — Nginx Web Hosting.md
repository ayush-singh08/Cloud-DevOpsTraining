## Overview

Deployed and configured an **Ubuntu Linux Virtual Machine on Microsoft Azure** and used Nginx to host a static website.

## Tasks Completed

### 1. Ubuntu VM Deployment

- Created an Ubuntu VM in Azure.
    
- Configured VM size, networking, authentication, and public IP.
    
- Connected to the VM using **SSH**.
    

![[Pasted image 20260813021532.png]]

### 2. Nginx Web Hosting

Installed and configured Nginx:

```bash
sudo apt update
sudo apt install nginx
sudo systemctl status nginx
```

- Hosted a static website using Nginx.
    
- Configured the required network access.
    
- Accessed the website through the VM's public IP.
