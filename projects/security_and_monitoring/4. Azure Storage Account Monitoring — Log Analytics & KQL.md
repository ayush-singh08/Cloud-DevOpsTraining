### 3. Analyzed Logs Using KQL

Used **KQL (Kusto Query Language)** to query and analyze the collected storage logs.

Example:

```kusto
StorageBlobLogs
| where TimeGenerated > ago(1h)
| limit 20
```

Also explored filtering and selecting specific fields from the collected logs.
