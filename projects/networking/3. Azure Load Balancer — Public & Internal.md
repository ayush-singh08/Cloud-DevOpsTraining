## Overview

Hands-on practice with **Azure Load Balancers** to distribute network traffic across multiple Virtual Machines.

## Tasks Completed

### 1. Public Load Balancer

- Created a **Public Load Balancer**.
    
- Configured a frontend public IP.
    
- Added backend VMs to the backend pool.
    
- Configured health probes and load-balancing rules.
    
- Accessed the application through the load balancer's public IP.
