# Linux Networking, Processes & Editors

## 1. Networking

### IP Address

Show network interfaces and IP addresses:

```bash
ip addr
````

Short form:

```bash
ip a
```

Show the machine's IP addresses:

```bash
hostname -I
```

---

### Routing Table

```bash
ip route
```

Shows how the machine sends traffic to different networks.

Example:

```text
default via 10.0.1.1 dev eth0
10.0.1.0/24 dev eth0
```

---

### Test Connectivity

Test another host:

```bash
ping <ip-address>
```

Test Internet connectivity:

```bash
ping 8.8.8.8
```

Test DNS + Internet:

```bash
ping google.com
```

> `ping 8.8.8.8` tests connectivity without relying on DNS.  
> `ping google.com` tests both connectivity and DNS resolution.

---

### Check Listening Ports

```bash
ss -tuln
```

Common options:

|Option|Meaning|
|---|---|
|`-t`|TCP|
|`-u`|UDP|
|`-l`|Listening|
|`-n`|Don't resolve names|

Check a specific port:

```bash
ss -tuln | grep :80
```

---

### Test HTTP Services

```bash
curl http://localhost
```

Test another machine:

```bash
curl http://10.0.2.4
```

Show HTTP headers:

```bash
curl -I http://example.com
```

Download a file:

```bash
wget <URL>
```

---

### DNS

Check DNS configuration:

```bash
cat /etc/resolv.conf
```

---

# 2. Processes

### List Processes

```bash
ps
```

Detailed process list:

```bash
ps aux
```

Search for a process:

```bash
ps aux | grep nginx
```

---

### Interactive Process Monitoring

```bash
top
```

Alternative:

```bash
htop
```

`top` displays CPU, memory, and running processes.

---

### Find Process ID

```bash
pgrep nginx
```

or:

```bash
pidof nginx
```

---

### Terminate a Process

Gracefully terminate:

```bash
kill <PID>
```

Force termination:

```bash
kill -9 <PID>
```

> Prefer normal `kill` first. Use `kill -9` only when a process does not terminate normally.

---

# 3. System Services

Modern Ubuntu systems commonly use **systemd** to manage services.

### Check Service Status

```bash
sudo systemctl status nginx
```

---

### Start a Service

```bash
sudo systemctl start nginx
```

### Stop a Service

```bash
sudo systemctl stop nginx
```

### Restart a Service

```bash
sudo systemctl restart nginx
```

### Reload Configuration

```bash
sudo systemctl reload nginx
```

Reload applies configuration changes without completely stopping the service.

---

### Enable Service at Boot

```bash
sudo systemctl enable nginx
```

Disable:

```bash
sudo systemctl disable nginx
```

Check whether it is enabled:

```bash
systemctl is-enabled nginx
```

---

### View Service Logs

```bash
journalctl -u nginx
```

Follow logs:

```bash
journalctl -u nginx -f
```

---

# 4. Text Editors

## Nano

Open/create a file:

```bash
nano file.txt
```

Common shortcuts:

|Shortcut|Action|
|---|---|
|`Ctrl + O`|Save|
|`Ctrl + X`|Exit|
|`Ctrl + W`|Search|
|`Ctrl + K`|Cut line|
|`Ctrl + U`|Paste|

---

## Vim

Open a file:

```bash
vim file.txt
```

Basic modes:

```text
Normal Mode → Navigation/commands
Insert Mode → Enter text
```

Enter insert mode:

```text
i
```

Save and exit:

```text
Esc
:wq
```

Exit without saving:

```text
Esc
:q!
```

# Key Concepts

- **IP Address** → Identifies a machine/interface on a network.
    
- **Routing Table** → Determines where network traffic is sent.
    
- **Port** → Identifies a network service.
    
- **Process** → A running instance of a program.
    
- **Service** → A managed background application.
    
- **systemd** → Service and system manager used by Ubuntu.
    
- **Logs** → Important for monitoring and troubleshooting.
