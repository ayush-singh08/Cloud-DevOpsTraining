# Linux Package Management

Ubuntu/Debian-based systems use **APT** to manage software packages.

---

## 1. Update Package Lists

```bash
sudo apt update
````

Downloads the latest package information from configured repositories.

> `apt update` does **not** upgrade installed packages.

---

## 2. Upgrade Packages

```bash
sudo apt upgrade
```

Updates installed packages to newer versions.

Update and upgrade together:

```bash
sudo apt update && sudo apt upgrade
```

---

## 3. Install a Package

```bash
sudo apt install nginx
```

Install multiple packages:

```bash
sudo apt install git curl wget
```

Install without confirmation:

```bash
sudo apt install -y nginx
```

---

## 4. Remove a Package

Remove the application:

```bash
sudo apt remove nginx
```

Remove the application and its configuration files:

```bash
sudo apt purge nginx
```

Remove unused dependencies:

```bash
sudo apt autoremove
```

---

## 5. Search for Packages

```bash
apt search nginx
```

Show package information:

```bash
apt show nginx
```

---

## 6. Check Installed Packages

```bash
apt list --installed
```

Check a specific package:

```bash
apt list --installed | grep nginx
```

---

## 7. `apt` vs `apt-get`

Both are used for package management.

```bash
apt
```

- User-friendly
    
- Recommended for interactive use
    

```bash
apt-get
```

- Older, lower-level interface
    
- Common in scripts and automation
    

Example:

```bash
sudo apt install nginx
```

---

## 8. Common Package Workflow

```bash
sudo apt update
sudo apt install <package>
```

After installation, verify the application:

```bash
<command> --version
```

Example:

```bash
nginx -v
```

---

## 9. Practical Usage

During the training, APT was used to install and manage services such as NGINX.

Example:

```bash
sudo apt update
sudo apt install nginx
```

Verify:

```bash
nginx -v
```

Check the service:

```bash
sudo systemctl status nginx
```

---

## Quick Reference

|Command|Purpose|
|---|---|
|`apt update`|Update package lists|
|`apt upgrade`|Upgrade installed packages|
|`apt install`|Install package|
|`apt remove`|Remove package|
|`apt purge`|Remove package + configuration|
|`apt autoremove`|Remove unused dependencies|
|`apt search`|Search packages|
|`apt show`|Package information|
|`apt list --installed`|List installed packages|

## Key Concept

```text
apt update
    ↓
Refresh package information

apt upgrade
    ↓
Upgrade installed packages

apt install
    ↓
Install new software
```
