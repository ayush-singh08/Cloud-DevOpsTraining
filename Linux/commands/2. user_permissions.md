
# Linux Users & Permissions

## 1. Current User

```bash
whoami
````

Shows the currently logged-in user.

```bash
id
```

Shows user ID (UID), group ID (GID), and group memberships.

---

## 2. User Information

List users:

```bash
cat /etc/passwd
```

List groups:

```bash
cat /etc/group
```

---

## 3. Switching Users

Switch to another user:

```bash
su username
```

Switch to root:

```bash
sudo su
```

Start a root login shell:

```bash
sudo -i
```

Exit the current user/shell:

```bash
exit
```

---

## 4. `sudo`

Execute a command with elevated privileges:

```bash
sudo command
```

Examples:

```bash
sudo apt update
sudo systemctl restart nginx
```

Check sudo privileges:

```bash
sudo -l
```

---

## 5. File Permissions

Check permissions:

```bash
ls -l
```

Example:

```text
-rwxr-xr-- 1 user group 1234 file.sh
```

Permission groups:

```text
-rwxr-xr--
 │││ │││ │││
 │││ │││ └── Others
 │││ └────── Group
 │└───────── Owner
 └────────── File type
```

Permissions:

|Symbol|Permission|
|---|---|
|`r`|Read|
|`w`|Write|
|`x`|Execute|
|`-`|No permission|

---

## 6. `chmod`

Change permissions.

Using symbols:

```bash
chmod u+x script.sh
chmod g+w file.txt
chmod o-r file.txt
```

Using numeric notation:

```bash
chmod 755 script.sh
chmod 644 index.html
```

### Numeric permissions

|Value|Permission|
|--:|---|
|`4`|Read|
|`2`|Write|
|`1`|Execute|
|`0`|None|

Example:

```text
755 = rwxr-xr-x
644 = rw-r--r--
```

---

## 7. `chown`

Change file owner:

```bash
sudo chown user file.txt
```

Change owner and group:

```bash
sudo chown user:group file.txt
```

Recursive:

```bash
sudo chown -R user:group directory/
```

---

## 8. `chgrp`

Change group ownership:

```bash
sudo chgrp group file.txt
```

---

## 9. Users

Create a user:

```bash
sudo adduser username
```

Delete a user:

```bash
sudo deluser username
```

Add user to a group:

```bash
sudo usermod -aG group username
```

Example:

```bash
sudo usermod -aG sudo username
```

---

## 10. Groups

Create a group:

```bash
sudo groupadd developers
```

Add a user:

```bash
sudo usermod -aG developers username
```

Check groups:

```bash
groups username
```

---

## 11. Password

Set/change a user's password:

```bash
sudo passwd username
```

Check password status:

```bash
sudo passwd -S username
```

When an Azure VM is created using **SSH key authentication**, the SSH key is used for login and the user may not have a usable password.
